# 데이터 제공처 조사 위치

일정 수집·정규화·제공처 관리는 별도 `godieor-backend`의 책임으로 옮겼다.
초기 조사 원본은 [backend의 데이터 제공처 문서](https://github.com/joobang/godieor-backend)에 있으며
저장소 안의 경로는 `docs/data-sources.md`다. 현재 변경이 로컬 문서에만 있다면 원격에서 아직 보이지 않을 수 있다.
로컬에서는 형제 폴더 `godieor-backend/docs/data-sources.md`를 읽는다.

초기 조사일은 2026-11-06이다. 2026-11-09 문서 정리에서 새로운 API 호출이나 조건 재검증은 하지 않았다.
범위 선택과 갱신 정책은 [공통 정책 P04~P08](system/policies.md)을 먼저 결정한다.
