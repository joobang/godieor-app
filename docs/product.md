## 아직 확정하지 않은 정책

- backend framework=NestJS, DB=PostgreSQL, ORM=Prisma, TypeORM 제외는 2026-11-09 사용자 확정.
  최종 실행 위치는 본인 iPhone 앱 + 클라우드 API/DB, Mac verifier로 확정했다. 첫 개발 목표는 로컬 실행이다.
  현재 SwiftUI·iOS 17 이상 구성을 유지한다. 로컬 backend/DB 버전은 공통 정책 하단과 backend 실행 문서에 고정했다.
  클라우드 제공자·실기기 설치/배포 수단은 미정이다.
- 로그인: 계정 기반 + Google 연동을 V1 방향으로 사용자 선택했다.
  로그인 없는 기기 전용 계정 제안은 대체한다. 개인 설정·찜의 계정 저장/복원은 확정했고, 세션·동기화 충돌·계정 삭제 상세는 추가 설계한다.
- 대상 OTT 4곳은 확정했다. 실제 작품의 지역/플랫폼별 최초 공개일 근거를 확보하고 미지원/누락 범위를 명시한다.
  국가별 플랫폼 가용성만으로 공개 날짜를 추정하지 않는다.
- 업데이트 주기는 하루 1회로 확정했다. 실패 시 마지막 데이터·성공 시각, 연기/취소 상태 표시를 확정했다. 실제 실행 시각·재시도·캐시 기한은 추가 설계한다.
- 작품·개별 일정 찜 모두 지원한다. 사용자 동작은 관심 대상 저장으로 통일하는 방향이며 상속·해제 UI는 설계 제안이다.
- 수익화·App Store 공개 시점·AI 모델/예산·실행 격리 방식은 미정.

## 일정 데이터 설계 원칙

콘텐츠 ID와 공개 이벤트 ID를 분리한다. 이벤트에는 콘텐츠 참조, release kind, 지역,
플랫폼 목록, 출처 이벤트 키, 상태, 원본 수정 시각, 수집 시각을 둔다.
중복 기준은 제목이 아니다. 출처의 안정적인 이벤트 ID를 우선 사용하고,
다른 출처의 병합은 지역·공개 방식·시간 정밀도를 확인한 뒤 수행한다.
일정이 변경돼도 기존 이벤트 ID와 수정 이력을 유지한다.

시간 값은 다음 세 형태를 구분한다.

- `instant`: offset이 있는 실제 시각을 UTC로 저장하고 사용자 시간대로 표시.
- `date_only`: 해당 지역의 달력 날짜를 그대로 보존. UTC 자정으로 변환하지 않음.
- `unknown`: 달력 날짜 없음. 연도·월·분기만 아는 경우 원본 정밀도를 별도로 보존하고 날짜를 만들지 않음.

플랫폼 가용성은 공개 이벤트의 근거와 별개다. ‘한국 Netflix에서 볼 수 있음’은
‘이 날짜에 한국 Netflix 공개’의 증거가 아니다.

- 로그인 전 캘린더·상세 조회 허용. 찜·설정의 계정 저장/복원은 Google 로그인 후 제공.

- OTT는 시즌별 최초 공개를 포함하며 회차별 공개/완결은 계속 제외한다.


## OTT 정확한 날짜만 반영 · 2026-11-09 후속 확정

사용자가 “좋아 그렇게 진행하고 다음작업진행해봐”로 직전 제안을 수락했다.
공식 출처에서 연·월·일을 확인한 OTT 최초 공개 일정만 달력 반영 대상으로 삼는다.
연도·연월·분기만 있는 항목은 달력/공개 일정에 넣지 않고 후보로 보류해 추후 날짜 발표를 확인한다.
시각·시간대·시즌 번호는 확보한 값만 사용하고 없으면 생략/null로 보존한다. 시즌1·자정·UTC 시각을 만들어 넣지 않는다.
수집 후보를 발견한 것과 드라마/시장/플랫폼/최초 공개일을 검토한 것, 제품에 publish한 것을 구분한다.
공식 공지 기반 후보 수집→검토 입력을 우선 진행하며 모든 작품·국가의 전수 확보를 약속하지 않는다.
일반 unknown 타입·다른 분야 미정 목록은 유지한다. 이번 선택은 OTT 입력 반영 기준이며 기존 승인 acceptance를 자동 변경하지 않는다.

## OTT 종류 확대 · 2026-11-13 사용자 확정

사용자가 ‘OTT 영화·시리즈·예능·다큐 지원으로 정리’를 선택했다. 기존 드라마 우선/예능 후속 문구를 대체한다. 다큐 영화와 시리즈를 구분하며 형태·시즌·날짜를 추정하지 않는다. 한국 플랫폼별 최초 공개·정확한 날짜·시즌별 첫 공개 원칙은 유지한다. 애니·회차별 일정은 이번 확정에 포함하지 않는다. 제품 범위 확정과 독립 acceptance 승인은 별개다.

## 사용자 범위 확정 · 2026-11-16

사용자가 ‘애니도 포함해 OTT 전체 대조’를 선택했다. 위2026-11-13의애니후속경계를변경하고애니영화·시리즈를V1 OTT에포함한다. 일반회차는계속제외하고한국플랫폼·시즌첫날/날짜만·미정원칙을유지한다. 현재미일치26행중애니5행도일치대상에서제외하지않는다. 영화/시리즈형태는명시하며지원구현이일자검증이나독립승인완료를뜻하지않는다.


## 기본기능 목표·데이터 우선 진행 순서 · 2026-11-17 사용자 확정

사용자는 기본기능 완성을 우선 목표로 하고, 데이터 수집·적재를 완료한 뒤 배포 환경 설정·실제 배포를 진행하고, 남은 기본기능을 완료한 다음 디테일·디자인을 정리하기를 선택했다. 기존 분야·플랫폼·날짜/미정·계정 정책을 축소하거나 새로운 기능을 추가하는 결정이 아니다.

실행 순서는 docs/system/plan.md의4단계를 따른다. 수동 게시 건수나 일반적인 전체 진행률을 데이터100%로 해석하지 않는다. 확정한 범위의 수집→검토/정규화→DB/API→일일 갱신·실패/누락 처리를 완료 조건으로 구체화하며, 공개되지 않은 날짜를 만들어 넣거나 알려진 결함을 제외해 완료로 처리하지 않는다. 독립 acceptance 승인·제품PASS와 개발 단계 완료는 구분한다.
