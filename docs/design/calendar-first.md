- 날짜: 2026-11-09 KST. 상태: 제품 방향 반영 + 상세 UX 설계 제안. 런타임 미구현.
- 연결: PROD-001~005, PROD-007~009 / P03, P07, P09. 변경 범위: 세 레포 문서, 대화용 가상 화면안.
- 예상 실패: 캘린더 과밀, 분야 숨김 시 찜 삭제, 상속 찜을 해제했다고 오인, 같은 이벤트 중복, 시간대 이동 시 잘못된 날짜.
- 학습 연결: backend ADR-006을 원리/대안의 근거로 둔다. 중앙 LEARN 항목은 독립 근거 확인 후 연결하며 이번 화면 초안을 검증 성과로 등록하지 않는다.

## 사용자가 정한 방향

- 극장 영화 개봉일(상영관별 회차/좌석 예매 제외), OTT 드라마 최초 공개 일정, 게임 정식 출시, EPL 경기 일정.
- 작품과 개별 일정 찜 모두 지원한다. 대상마다 같은 수준의 저장 동작으로 느껴지도록 설계한다.
- 이번 달의 큰 캘린더가 메인. 기본은 영화·OTT, 설정에서 게임·EPL 추가.
- 분야·국가/시간대·보기·찜은 계정에 귀속하고 재로그인/재설치 때 복원.

## 화면 제안

1. 상단: GODIEOR, 월 이동/오늘, 표시 국가·시간대 요약.
2. 캘린더 위: 활성 분야 칩과 전체/찜만 전환. 칩은 현재 필터이며 설정의 분야 등록과 구분.
3. 중앙: 월 전체가 보이는 7열 그리드. 제목 1~2줄과 `+N`; 포스터는 상세/목록에서 표시.
4. 날짜 선택: 아래 해당 날짜 목록. 제목, 극장/OTT/게임/EPL 구분, 공개일 또는 시각, 상태와 찜 동작.
5. 하단: 캘린더 / 찜 / 설정. 날짜순 카드 보기는 캘린더의 보기 전환으로 유지.
6. 미정 일정은 날짜 칸 밖의 별도 진입점. 월별 정확한 날짜 합계에 미정/월만 아는 일정을 포함하지 않음.

사용자가 캘린더 중심안을 선택해 이 안으로 진행한다. 캘린더와 목록을 반씩 보여주는 안은 비교 이력으로 남긴다.
초안의 예시 제목·경기·날짜는 모두 가상이며 실제 개봉/편성/경기 일정을 뜻하지 않는다.
실제품에서 실제 확인되지 않은 kickoff는 가상 시각 대신 미정으로 표시한다.
최소 글자 크기/44pt 터치 영역/큰 글자에서 목록 전환과 줄 수 조정은 iOS 구현 시 설계한다.

## 찜 동작 제안

| 저장 대상 | 사용자의 의미 | 모이는 일정 |
|---|---|---|
| 영화 작품 | 이 영화가 궁금함 | 지원 범위의 극장 개봉 이벤트, 향후 OTT 영화 지원 확대 시 별도 정책 |
| OTT 드라마 작품 | 이 드라마가 궁금함 | 지원 지역·플랫폼의 최초 공개 일정(시즌 포함 여부 확인 중) |
| 게임 작품 | 이 게임이 궁금함 | 지원 기기의 정식 출시 이벤트 |
| EPL 한 경기 | 이 경기를 보고 싶음 | 해당 경기 하나 |
| 상세의 최초 공개/개봉/출시 이벤트 | 이것만 따로 저장 | 해당 이벤트 하나 |

목록의 기본 동작은 `찜`으로 통일한다. 작품 상세는 `작품 찜`, 일정 상세는 `이 일정 저장`으로 대상을 명확히 한다.
작품 찜에 포함된 공개 이벤트는 `작품 찜에 포함`으로 표시한다. 이것을 직접 저장 토글의 ON으로 표시하지 않는다.
직접 저장은 별도 해제 가능하며 작품 찜을 해제해도 직접 저장한 일정은 유지한다. 작품 찜의 상속만 남으면 찜 일정에서 여전히 보인다고 안내한다.
작품 찜은 공개 이벤트마다 사용자 저장 행을 생성하지 않는다. 새 일정도 조회 시 관련 일정으로 포함한다.
같은 이벤트를 작품과 일정 양쪽에서 찜해도 한 번 표시한다. 날짜 변경/연기 시 이벤트 ID와 찜 연결을 유지한다.
EPL 팀/리그 구독은 이번 요청에서 확대하지 않는다. 알림 전송도 찜과 별도 기능이다.

## 분야 설정과 필터

- 신규 계정의 기본값: 영화·OTT ON, 게임·EPL OFF. 기존 계정 설정은 덮어쓰지 않는다.
- 게임/EPL OFF는 화면에서 숨김이다. 서버 수집 중단·기존 찜 삭제·계정 데이터 삭제가 아니다.
- 일반 캘린더는 활성 분야와 임시 필터의 교집합. 빈 임시 필터=활성 분야 전체.
- 모든 분야를 끈 경우에는 분야 추가 안내. 이를 빈 필터와 혼동해 전체 데이터를 표시하지 않는다.
- 찜 탭에는 저장한 모든 대상을 보존하고 숨긴 분야임을 표시한다. 찜만 캘린더에는 활성 분야 조건을 적용한다.
- 연기·취소/최신성·제공처 미지원 표시는 목록/상세에 유지. 색상 외 텍스트로 분야를 구별한다.
