- 최근 한 달보다 오래된 일정은 탐색 달력에서 제외한다. 플랫폼마다 날짜/시각·상태가 달라지는 출시와 기존 공개 ID를 보존한다.
- 경계 조건: 월말과 시간대에서 하루 차이, 다른 날짜·지역·상태·정밀도의 같은 작품, 플랫폼 필터, 이미지 없는 화면, 오래된 일정의 찜/상세 접근.

- 보라색 포인트와 밝은 배경·흰 카드 적용. 달력은 일정이 있는 날을 점으로, 일간 목록은 실제 카드 수로 표시한다. WORLD 일정에 글로벌 표기.
- 같은 콘텐츠 ID·지역·시각/날짜 정밀도·상태·원천인 게임만 카드로 묶는다. 상세 플랫폼 메뉴에는 각 이벤트를 별도로 열 수 있다.
- iPhone 17 Simulator 밝은 홈/상세 확인. 운영 Dark Rail 동일 가족 플랫폼 2개를 목록 카드 1개에서 원본 2개로 선택 가능 확인. 합성 Swift 테스트에서 플랫폼 3종과 다른 날짜·지역·이벤트·원천 분리, 계정 회귀 15/15 성공.
- 사용자가 정한 최근 한 달은 표시 시간대에서 한 달 전 같은 날짜부터 포함하고 DB 이력은 보존한다. 운영 API 조회 및 WORLD 실제 실행은 backend DATA-92 참고. ADR/LEARN 신규 해당 없음. 담당 해제.
